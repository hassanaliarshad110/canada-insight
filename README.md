# Canada Insight

Independent civic research on Canadian cities from official open data. Calgary is the first city; others are added
by configuration, not code.

**First module: access to everyday amenities.** For every home on the city's property roll, the distance to the
nearest playground, park, transit stop, community centre, indoor recreation centre and library in the city's own
inventory, summarised by community, with homes built since the 2021 Census measured separately so you can see
whether growth has been matched.

Documentation is being written; see `docs/`.
